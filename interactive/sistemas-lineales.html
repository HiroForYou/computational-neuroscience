Sistemas lineales 2DPuntos fijos, autovalores y retratos de fase

Todo análisis de estabilidad (de una neurona de Hodgkin–Huxley o de una red de Wilson–Cowan) termina en una matriz de 2×2 como esta. Cambia sus coeficientes, haz clic en el plano de fase para lanzar trayectorias y mira cómo los autovalores deciden si el origen atrae, repele o hace girar.

Plano traza–determinante

Cada matriz es un punto. La parábola Δ = τ²/4 separa focos (autovalores complejos) de nodos. Haz clic para elegir otro punto.

Las ecuaciones

d/dt (x, y)ᵀ = A (x, y)ᵀ,    A = [[a, b], [c, d]]

El origen siempre es un punto fijo. Los autovalores son las raíces de λ² − τλ + Δ = 0:

λ1,2 = τ/2 ± √(τ²/4 − Δ),    τ = a + d,   Δ = ad − bc

Si los autovectores vi son independientes, la solución es x(t) = c₁ eλ₁t v₁ + c₂ eλ₂t v₂. Cada término crece si Re λ > 0 y se apaga si Re λ < 0.

Las trayectorias se integran con Runge–Kutta de cuarto orden (Δt = 0,01).

Por qué importa en neurociencia

  • Linealización. Un modelo no lineal ẋ = f(x) se comporta cerca de un punto fijo x* como ẋ ≈ J (x − x*), con J el jacobiano. La matriz A de este módulo es ese jacobiano.
  • Reposo estable. Una neurona en reposo es un punto fijo estable: pequeñas perturbaciones se apagan. Si es un foco, la vuelta al reposo es oscilatoria (como las oscilaciones subumbral).
  • Bifurcación de Hopf. Cuando un foco estable cruza τ = 0 se vuelve inestable y en el sistema no lineal nace una oscilación: así empieza a disparar Hodgkin–Huxley con corriente sostenida y así oscila Wilson–Cowan. Muévete en el plano traza–determinante a través del eje vertical para verlo.
  • Sillas y umbrales. El autovector estable de una silla separa trayectorias que van a destinos distintos: es la idea geométrica de un umbral de disparo o de una frontera entre memorias.
